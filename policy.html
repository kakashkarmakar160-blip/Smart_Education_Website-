Policy, Rules & ব্যবহারের সম্পূর্ণ নির্দেশিকা

এই পেজে কোন ফিচার কী করে এবং কীভাবে তৈরি/ব্যবহার করতে হবে—দুটিই বলা আছে। Menu থেকে সংশ্লিষ্ট পেজ খুলে ধাপগুলো অনুসরণ করুন।

বাইরের ওয়েবসাইট/ভিডিও মিটিং পরিষেবার নিজস্ব নিয়মও প্রযোজ্য। Cloud সুবিধা Supabase configuration, network ও access policy ঠিক থাকার ওপর নির্ভরশীল।

1. Settings ও DP কীভাবে সেট করবেন

ধাপ ১: Teacher Profile বা Student Profile থেকে ⚙ Settings খুলুন।
ধাপ ২: Account Type থেকে Student DP বা Teacher DP বেছে নিন। একই account-এর role অনুযায়ী সঠিক DP field বাছুন।
ধাপ ৩: JPG/PNG/WebP ছবি নির্বাচন করুন; ফাইল 300 KB-এর মধ্যে রাখুন। Preview দেখে Save DP চাপুন।

ছবি সেভ হলেও না দেখালে page refresh করুন এবং profile-এর একই account দিয়ে ঢুকেছেন কি না দেখুন। Browser-এ cloud save সফল হওয়ার জন্য profiles table ও RLS policy সঠিক থাকতে হবে।

2. Teacher কীভাবে Group তৈরি করবেন

ধাপ ১: Teacher Profile → Groups & Chat খুলুন।
ধাপ ২: Create Group-এ Group Name, Class, Semester/Subject, Description দিন। চাইলে 300 KB-এর মধ্যে Group Logo নির্বাচন করুন।
ধাপ ৩: Create Group & Generate Code চাপুন। তৈরি হওয়া code ছাত্রদের দিন।

Group তৈরির শিক্ষকই Admin। কেবল Admin Group Name/Logo পরিবর্তন, সদস্য যোগ/বাদ এবং গ্রুপ পরিচালনা করতে পারবেন। Student profile-এ শুধু Open Group থাকবে; সেখানে Create Group form থাকবে না।

3. Student কীভাবে Group-এ ঢুকবে ও Chat করবে

ধাপ ১: Student Profile → Open Group চাপুন।
ধাপ ২: Teacher-এর দেওয়া Group Code লিখে Join Group চাপুন। একজন Student একাধিক Group-এ যোগ দিতে পারে।
ধাপ ৩: My Groups তালিকায় সংশ্লিষ্ট Group-এর Open Chat চাপুন। মেসেজ লিখে Send করুন।

একই Group-এর Teacher Admin এবং যোগ দেওয়া সব Student একসঙ্গে মেসেজ দেখতে ও পাঠাতে পারবে। Student অন্য কাউকে যোগ/বাদ দিতে, Group Name বদলাতে বা Logo বদলাতে পারবে না। Student নিজে Leave করতে পারবে।

4. Teacher কীভাবে Create with Link করবেন

ধাপ ১: Teacher Profile-এ 🔗 Create with Link অংশে যান।
ধাপ ২: Link-এর নাম লিখুন (যেমন Notice), তারপর সম্পূর্ণ URL দিন—যেমন https://example.com/notice।
ধাপ ৩: Publish & Generate Code চাপুন। স্ক্রিনে একটি unique Link Code দেখাবে। Code কপি করে Student-দের দিন।

এই feature একটি বাইরের URL-কে code দিয়ে খোলার ব্যবস্থা করে; এটি নিজে Notice editor তৈরি করে না এবং URL নিরাপদ কি না যাচাই করতে পারে না। কেবল বিশ্বস্ত URL দিন।

5. Student কীভাবে Open Link করবে

ধাপ ১: Student Profile-এ 🔗 Open Link অংশে যান।
ধাপ ২: Teacher-এর দেওয়া Link Code পেস্ট/লিখুন।
ধাপ ৩: Open Link চাপুন। Teacher যে URL publish করেছিলেন সেটি নতুন tab-এ খুলবে।

Code না খুললে code-এর বানান/হাইফেন ঠিক আছে কি না দেখুন এবং Teacher link publish করেছেন কি না নিশ্চিত করুন।

6. Notice কীভাবে তৈরি করবেন

ধাপ ১: Teacher Profile থেকে Make Notes/Notes editor খুলুন।
ধাপ ২: Title, Class, Semester, Subject, Chapter ও Teacher Name পূরণ করুন। Notice-এর মতো সাধারণ লেখা তৈরি করতে editor-এ লেখা লিখুন; প্রয়োজন হলে ছবি/heading ব্যবহার করুন।
ধাপ ৩: Publish চাপুন এবং তৈরি হওয়া Notes Code Student-দের দিন।
বাইরের Notice URL হলে: Create with Link ব্যবহার করুন; URL publish করে পাওয়া Link Code Student-কে দিন।

Notice/Notes-এর প্রকাশনা ও student access সংশ্লিষ্ট notes table এবং তার RLS policy ঠিক থাকার ওপর নির্ভর করে।

7. Video Conference / Live Class কীভাবে করবেন

ধাপ ১: Teacher Profile → Live Class খুলুন। Browser-এ camera/microphone permission চাইলে অনুমতি দিন।
ধাপ ২: ক্লাসের link/code বা room তথ্য ছাত্রদের জানান। Student Profile → Live Class থেকে প্রবেশ করবে।
ধাপ ৩: PDF/Notes দেখানো বা Screen Share করার আগে উপযুক্ত Insert/Draw/View/Screen Share control ব্যবহার করুন; মোবাইলে browser/WebView-এর সীমাবদ্ধতা থাকতে পারে।

শিক্ষার্থীদের জানিয়ে camera, microphone বা screen share ব্যবহার করুন। অনুমতি ছাড়া ক্লাস রেকর্ড/প্রকাশ করবেন না। বাইরের meeting provider-এর privacy ও safety settings-ও পরীক্ষা করুন।

8. Question Paper ও Exam কীভাবে তৈরি করবেন

ধাপ ১: Teacher Profile → Create Question খুলুন। প্রশ্ন, options/answer, marks ও প্রয়োজনীয় metadata দিন।
ধাপ ২: Preview দেখে Publish করুন। তৈরি হওয়া access code শিক্ষার্থীদের দিন।
ধাপ ৩: Student Profile থেকে Open Teacher Paper খুলে code ব্যবহার করে পরীক্ষা দেবে। ফলাফল profile/result অংশে দেখা যাবে।

পরীক্ষার উত্তর নিজে দিন; অন্যের হয়ে পরীক্ষা দেওয়া বা result বদলানোর চেষ্টা করবেন না।

9. Profile, Result ও Student DP

Student Profile-এ নিজের DP, ফলাফল ও Live Class stars দেখা যায়। Teacher Profile-এর published paper-এর result list-এ student নামের পাশে DP দেখানোর চেষ্টা করা হয়। ছবি না থাকলে initials দেখা যেতে পারে। DP আলাদা field-এ সেভ হয়: Student DP এবং Teacher DP।

10. Privacy, Group Admin ও নিরাপত্তা নীতি

  • নিজের account ব্যবহার করুন; অন্যের পরিচয় ব্যবহার করবেন না।
  • Group code এবং Link Code শুধু সংশ্লিষ্টদের দিন। Code জানা মানে বাইরের URL নিরাপদ—এমন নয়।
  • Teacher Admin-ই Group Name, Logo ও membership পরিচালনা করবেন।
  • Student অন্য Student-কে যোগ/বাদ দিতে বা Group-এর পরিচয় বদলাতে পারবে না।
  • ছবি 300 KB-এর মধ্যে রাখুন; অনুমতি ছাড়া অন্যের ছবি/ফলাফল শেয়ার করবেন না।
  • Chat-এ হয়রানি, স্প্যাম, ব্যক্তিগত তথ্য, প্রতারণামূলক বা বেআইনি কনটেন্ট দেবেন না।
  • ব্যক্তিগত OTP, password, payment details বা গোপন তথ্য কোনো shared link-এ দেবেন না।
  • Cloud data-এর নিরাপত্তা Supabase RLS, project settings এবং database policies সঠিকভাবে চালু থাকার ওপর নির্ভর করে।

এই নির্দেশিকা প্রয়োজন অনুযায়ী আপডেট হতে পারে। কোনো feature কাজ না করলে সংশ্লিষ্ট error message ও SQL setup status পরীক্ষা করুন।
