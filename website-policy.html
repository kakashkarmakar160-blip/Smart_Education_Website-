Smart Education — সম্পূর্ণ ব্যবহার নির্দেশিকা ও Policy

এই গাইডে Home, Student, Teacher, Exam, Groups, Classes, Notes, Live Class, AI এবং Settings-এর ব্যবহার ধাপে ধাপে দেওয়া হলো। তোমার account-এর role অনুযায়ী যেসব বাটন দেখা যায় সেগুলো ব্যবহার করবে। কোনো বাটন না দেখালে সংশ্লিষ্ট feature তোমার বর্তমান পেজে নেই।

কিছু ফিচার Supabase setup, Internet, Browser permission এবং শিক্ষক/শিক্ষার্থীর access-এর ওপর নির্ভরশীল।

১. Home ও Navigation

  • Student: Student Profile খোলে। নিজের ফলাফল, পরীক্ষা, Notes/Notice, Group এবং উপলব্ধ class/resource ব্যবহার করবে।
  • Teacher: Teacher Profile খোলে। Question Paper, Exam Results, Classes, Notes, Live Class এবং Groups পরিচালনা করবে।
  • Computer: Computer Room খোলে; উপলব্ধ computer learning content/teacher class দেখা যায়।
  • Hat/Cap Menu: Student বা Teacher পেজে পাশের Sidebar খুলে। X চাপলে বা বাইরের shade-এ চাপলে বন্ধ হয়।
  • Profile Avatar: Profile পেজে যায়। Theme বাটন Light/Dark বদলায়।
  • Back: যেসব পেজে Back আছে সেখানে আগের/নির্ধারিত পেজে ফেরে। Student Exam চলাকালে Back ও AI Assistant দেখানো হয় না।

২. Student Profile ও পরীক্ষা

Student Profile

  • Exam / Practice: উপলব্ধ প্রশ্ন সেট বেছে পরীক্ষা/অনুশীলন শুরু করো।
  • Open Teacher Paper: শিক্ষক দেওয়া Paper Code লিখে প্রকাশিত প্রশ্নপত্র খোলো।
  • Results / Marksheet: নিজের জমা দেওয়া পরীক্ষার ফল, নম্বর ও মার্কশিট দেখো; Edit সুবিধা শুধু যেখানে অনুমোদিত সেখানে থাকবে।
  • Notes / Notice: শিক্ষক প্রকাশিত Notes বা Code/Link দিয়ে পাওয়া Notice খোলো।
  • Groups & Chat: নিজের গ্রুপ খোলো, Code দিয়ে Join করো এবং সদস্যদের সঙ্গে কথা বলো।
  • Live Class: শিক্ষক দেওয়া Room/Link দিয়ে ক্লাসে যোগ দাও।
  • Computer Room / Classes: উপলব্ধ শেখার উপকরণ ও শিক্ষক ক্লাস দেখো।

Student Exam Interface

  • প্রশ্ন ও Options পড়ে একটি উত্তর বেছে নাও।
  • Previous / Next Question দিয়ে প্রশ্ন বদলাও; এটি প্রশ্নের ভেতরের navigation, পেজের Back নয়।
  • Timer শেষ হলে পেজের নিয়ম অনুযায়ী পরীক্ষা শেষ/জমা হতে পারে। নেটওয়ার্ক চালু রাখো।
  • Student Exam পেজে AI Assistant এবং header Back button নেই। Calculator থাকলে সেটি আলাদা utility; উত্তর জমা দেওয়ার আগে নির্দেশনা অনুসরণ করো।
  • Submit করার আগে উত্তর যাচাই করো; জমা দেওয়ার পর পরিবর্তন নাও করা যেতে পারে।

৩. Teacher Profile ও Sidebar

  • Exam Results: নিজের প্রকাশিত প্রশ্নপত্র এবং সেই Paper-এ পরীক্ষা দেওয়া Student-এর ফলাফল দেখো। Preview/Edit লিংক থাকলে সেখান থেকে Marksheet দেখো বা অনুমোদিত পরিবর্তন করো।
  • Create Question Paper: প্রশ্ন তৈরি, Options/সঠিক উত্তর, Marks ও প্রয়োজনীয় বিবরণ দিয়ে Preview করো; তারপর Publish করে Code শিক্ষার্থীদের দাও।
  • Create & Manage Classes: নিজের Class তৈরি/প্রকাশ, Resource যোগ, Admission Request দেখা এবং Enrolled Student পরিচালনা করো। এই অংশ Delete All Question Papers দিয়ে মুছবে না।
  • Create Notes: Title, Class, Semester, Subject, Chapter ও Teacher Name দিয়ে Notes তৈরি, Preview ও Publish করো।
  • Live Class: ক্লাসের Room/Link তৈরি বা খুলে Browser permission অনুযায়ী Camera/Microphone/Screen Share ব্যবহার করো।
  • Groups & Chat: গ্রুপ খোলা, নিজের গ্রুপে Chat এবং Admin সুবিধা ব্যবহার করো।
  • Edit Teacher Profile: নিজের নাম/প্রোফাইল তথ্য ও উপলব্ধ DP পরিবর্তন করো।
  • Settings: DP, Design, Group Create, AI Key/Memory এবং Policy ব্যবহার করো।
  • Computer Room: Computer learning area খোলে।
  • Create with Link: Link-এর নাম ও পূর্ণ URL দিয়ে Publish & Generate Code করো; Code শিক্ষার্থীকে পাঠাও।

Delete All Question Papers — অত্যন্ত গুরুত্বপূর্ণ

Teacher Sidebar-এর লাল Delete All Question Papers বাটনটি শুধু বর্তমান Teacher-এর তৈরি Question Papers এবং ওই Paper-গুলোর সঙ্গে যুক্ত Student/Exam Results মুছে দেয়। Confirm করার পর এটি স্থায়ীভাবে মুছে যায়।

এতে কখনোই মুছে যাবে না: Create & Manage Classes, Class Resources, Groups & Chat, Group Logo, Group Code, Group Members, অন্য Teacher-এর Papers/Results, Profile বা AI Memory। ভুল এড়াতে Confirmation পড়ে তারপর চাপবে।

৪. Question Paper তৈরি ও Publish

ধাপ ১: Teacher Menu → Create Question Paper খোলো।
ধাপ ২: Paper-এর নাম/বিষয়/শ্রেণি এবং প্রশ্নের ধরন নির্বাচন করো। MCQ হলে প্রশ্ন, Option ও সঠিক উত্তর দাও; Long/Fill in the blank/Paragraph হলে নির্দেশ অনুযায়ী প্রশ্ন ও উত্তর/মান পূরণ করো।
ধাপ ৩: Marks ও প্রয়োজনীয় ছবি/বিবরণ যোগ করে Save/Preview করো।
ধাপ ৪: Preview ঠিক থাকলে Publish করো। তৈরি হওয়া Paper Code শিক্ষার্থীদের দাও।

Publish না করলে Paper শিক্ষার্থীর Code দিয়ে নাও পাওয়া যেতে পারে। Paper-এর Code ও নাম নিরাপদে রাখো।

৫. Create & Manage Classes / Admission

  • Teacher নিজের Class Name, School Class, Subject, Semester, Price ও Description দিয়ে Class তৈরি/Publish করে।
  • Class Logo এবং Resource Cover-এর ক্ষেত্রে পেজে দেওয়া file-size limit মানো।
  • PDF, Notes, Book, Recording, Live Class, Course ইত্যাদি Resource-এ সঠিক Title ও HTTPS URL দাও।
  • Student Class খুঁজে Admission Request পাঠালে Teacher request দেখে Accept/Reject করতে পারে।
  • শুধু Active/Accepted enrollment থাকলে Student protected resources দেখতে পারবে—এটি database policy/configuration অনুযায়ী নিয়ন্ত্রিত।
  • Teacher-এর Add Student by User ID সুবিধা থাকলে সঠিক Supabase User ID ব্যবহার করো; ভুল ID অন্য ব্যক্তিকে যুক্ত করতে পারে।
  • Price শুধু প্রদর্শিত মূল্য; আলাদা payment gateway না থাকলে ওয়েবসাইট নিজে টাকা সংগ্রহ করে না।

৬. Groups & Chat — Admin ও Member

Group তৈরি: Settings → Create Group-এ Group Name, Class ও Logo দাও; Create Group & Generate Code চাপো। Creator স্বয়ংক্রিয়ভাবে Admin হয়।
Code দিয়ে Join: Groups & Chat-এ Join by Code-এ Admin-এর দেওয়া Group Code paste করে Join করো।
User ID দিয়ে Add: Admin-এর Add Member অংশে সঠিক Student User ID দিয়ে Add করো, যদি ওই UI-তে অপশন থাকে।
Member Remove: Admin member list থেকে Remove করে সদস্যকে গ্রুপ থেকে বের করতে পারে। সাধারণ Member অন্যকে Remove করতে পারে না।
Chat: Group খুলে message লিখে Send করো। Group Logo/Name-এ চাপলে যদি member list/settings খোলে, সেখান থেকে সদস্য/তথ্য দেখো।

Group Code কেবল যাদের যোগ দিতে দিতে চাও তাদের পাঠাও। Admin-এর account হারালে গ্রুপ পরিচালনায় সমস্যা হতে পারে।

৭. Notes, Notice ও Shared Link

  • Teacher Notes: Notes editor-এ Title, Class, Semester, Subject, Chapter ও Teacher Name দাও; editor-এর formatting, heading, image ও math controls ব্যবহার করে Preview করো এবং Publish করো।
  • Student Notes: Student Notes অংশে শিক্ষক প্রকাশিত Notes বা দেওয়া Code দিয়ে খোলো।
  • Notice: Notes editor দিয়ে Notice লেখা/প্রকাশ করা যায় যদি Notes Publish workflow ব্যবহার করা হয়। বাইরের Notice URL হলে Create with Link ব্যবহার করো।
  • Create with Link: সম্পূর্ণ URL (যেমন https://example.com) লিখে Publish & Generate Code চাপো।
  • Open Link: Student-কে দেওয়া Link Code লিখে Open Link চাপতে হবে। অপরিচিত/সন্দেহজনক URL খুলবে না।

৮. Live Class ও Screen Share

  • Teacher Live Class পেজে Room/Link তৈরি বা নির্ধারিত ক্লাস খোলে এবং Student-দের Link/Code দেয়।
  • Student Live Class পেজে প্রবেশ করে Camera/Microphone permission চাইলে প্রয়োজন অনুযায়ী Allow করে।
  • Screen Share, Camera, Microphone এবং PDF/Notes annotation শুধু browser/device সমর্থন করলে কাজ করবে। Android browser-এ Screen Share সীমিত হতে পারে।
  • অন্যদের জানিয়ে রেকর্ড/স্ক্রিন শেয়ার করো। ক্লাসে শালীন আচরণ বজায় রাখো।

৯. Settings — প্রতিটি অংশের কাজ

  • Profile Photo / DP: Account Type থেকে Student DP বা Teacher DP বেছে JPG/PNG/WebP ছবি নির্বাচন করে Save DP চাপো। সর্বোচ্চ 300 KB সীমা মানো।
  • Display Settings: Toggle Dark/Light দিয়ে Theme বদলাও; Language থেকে বাংলা/English বেছে Save Language করো।
  • Create Group: Group Name, Class ও Logo দিয়ে Group তৈরি করো; তৈরি হওয়া Code অন্য সদস্যদের পাঠাও।
  • Design: Background Colour, Image URL বা Upload, Transparency, Font Size, Box Size, Brightness এবং Corner Roundness ঠিক করে Save Design চাপো। Image Upload সর্বোচ্চ 300 KB।
  • Reset Design: Design-এর নিজস্ব পরিবর্তন ডিফল্ট করে।
  • AI Assistant & Personal Memory: Gemini API Key সেভ, নিজের Memory-তে তথ্য যোগ, এবং AI Memory/Chats মুছে ফেলার ব্যবস্থা।
  • Reset All Settings: এই Browser-এর ব্যক্তিগত Design, Theme ও Language preferences ডিফল্ট করে। এটি Supabase-এর Classes, Groups, Members, Results বা Marksheet ডিলিট করার জন্য নয়। AI Memory/Chat মুছতে আলাদা Clear AI Memory & Chats ব্যবহার করো।
  • Policy: এই সম্পূর্ণ নির্দেশিকা আবার পড়ার জন্য।

১০. Gemini AI Assistant ও API Key

AI Assistant ব্যবহার করতে Google Gemini API Key প্রয়োজন। Key তৈরি করার অফিসিয়াল জায়গা: Google AI Studio — Get API Key।

ধাপ ১: উপরের Google AI Studio লিংকে চাপো। Google Account দিয়ে Sign in করো।
ধাপ ২: Get API Key / API keys পেজে যাও।
ধাপ ৩: Create API Key চাপো। প্রয়োজন হলে একটি Google Cloud Project বেছে নাও বা নতুন Project তৈরি করো।
ধাপ ৪: তৈরি হওয়া API Key Copy করো। Key কাউকে পাঠিও না, Screenshot-এ প্রকাশ করো না।
ধাপ ৫: Smart Education → Settings → AI Assistant & Personal Memory-তে গিয়ে Gemini API Key ঘরে Paste করো।
ধাপ ৬: Save API Key চাপো। এরপর AI Assistant বাটন থেকে Chat শুরু করো।
নিরাপত্তা ও খরচ: এই সাইটের বর্তমান ব্যবস্থা Key-কে Browser-এর Local Storage-এ রাখে; তাই একই Browser-এর DevTools/ডিভাইস অ্যাক্সেস পেলে Key দেখা সম্ভব। ব্যক্তিগত Key কারও সঙ্গে শেয়ার করবে না, Google AI Studio/Cloud-এ usage ও billing limit পরীক্ষা করবে। API usage free tier/paid tier ও Google-এর বর্তমান নিয়মের ওপর নির্ভরশীল।

AI Memory কীভাবে কাজ করে?

  • AI Chat-এর user message ও AI reply এই Browser-এর IndexedDB-তে থাকে।
  • Settings থেকে নিজের তথ্য Save to Personal Memory করে রাখতে পারো।
  • প্রশ্নের সময় সাম্প্রতিক Memory-র কিছু অংশ Gemini-কে পাঠানো হয়, যাতে প্রাসঙ্গিক উত্তর দিতে পারে।
  • Memory শুধু একই Browser/ডিভাইসে থাকে; অন্য ফোন/Browser-এ Sync হয় না। Browser data clear করলে Memory হারাতে পারে।
  • AI ভুল উত্তর দিতে পারে; গুরুত্বপূর্ণ পড়াশোনা/ফলাফল যাচাই করে নাও। AI-এর কাছে OTP, Password বা গোপন তথ্য লিখবে না।
  • Clear AI Memory & Chats চাপলে এই Browser-এর AI Memory ও Chat History মুছে যায়।

১১. Privacy, Data ও নিরাপত্তা Policy

  • Supabase-এ রাখা Profile, Question Paper, Result, Class, Group ও Chat database policies/RLS অনুযায়ী নিয়ন্ত্রিত হয়।
  • AI Chat এবং AI Memory আলাদা Browser storage-এ থাকে; এগুলো Supabase database-এ সেভ করার জন্য এই AI script ব্যবহার করে না। তবে প্রশ্নের উত্তর পেতে chat prompt ও নির্বাচিত Memory Gemini API-তে পাঠানো হয়।
  • নিজের User ID, Group Code, API Key, OTP বা Password প্রকাশ্যে শেয়ার করো না।
  • অন্যের Result বা ব্যক্তিগত তথ্য অনুমতি ছাড়া কপি/প্রকাশ করবে না।
  • শুধু নিজের বা ব্যবহারের অনুমতি থাকা ছবি, PDF, Notes ও URL আপলোড করো।
  • Browser, Network, Supabase policy বা third-party API সমস্যায় কিছু ফিচার সাময়িকভাবে কাজ নাও করতে পারে।

১২. সমস্যা হলে কী পরীক্ষা করবে

  • Login/Profile না খুললে Internet, Account Session ও Supabase connection পরীক্ষা করো।
  • Paper Code কাজ না করলে Code সঠিক কি না এবং Teacher Publish করেছেন কি না যাচাই করো।
  • Group Create/Join না হলে Group SQL setup, login এবং Group Code পরীক্ষা করো।
  • Resource না খুললে Enrollment Active কি না এবং URL HTTPS কি না দেখো।
  • AI উত্তর না দিলে API Key সঠিক কি না, Google AI Studio-তে API access/usage limit এবং Internet পরীক্ষা করো।
  • DP/Background save না হলে ফাইলের আকার, file type ও browser permission পরীক্ষা করো।

এই গাইডে UI ও বর্তমান browser/database আচরণ অনুযায়ী নির্দেশ দেওয়া হয়েছে। Google, Supabase ও video provider-এর নিজস্ব নিয়ম/সুবিধা সময়ের সঙ্গে বদলাতে পারে।
